## 1. `iapws95-benchmark.svg`

Regenerate: `HIP_VISIBLE_DEVICES=0 python figures/iapws95_benchmark.py`

```html
<figure class="panel-media">
  <img src="assets/projects/iapws95-benchmark.svg" alt="GPU vs CPU runtime benchmark, log-log scale" />
  <figcaption>
    IAPWS-95 property evaluation (&rho;, h, c<sub>p</sub>, &mu;, k), this library's
    GPU-batched implementation vs. the reference <code>iapws</code> PyPI package
    (pure-Python, one state point at a time). Measured on an AMD Radeon RX 7800 XT
    (ROCm 7.2, torch 2.9.1) against `iapws` on the same machine's CPU, both libraries run
    at every batch size up to 20,000 points: speedup grows from 1.2&times; at 100 points
    to <strong>59.9&times; at 20,000 points</strong> (both sides measured). Beyond that
    the pure-Python reference becomes impractical to run directly (an actual run at
    1,000,000 points would take on the order of 45 minutes); extrapolating its measured
    per-point cost gives an estimated <strong>~67&times; at 1,000,000 points</strong>,
    shown as a dashed line and explicitly labeled "extrapolated," not measured.
    Accuracy cross-checked against `iapws` at 300 random points, 280&ndash;800 K,
    0.5&ndash;100 MPa: max relative error 0.038% (c<sub>p</sub>), &lt;0.01% on the rest.
  </figcaption>
</figure>
```

**Note on the CV/page claim:** the CV states "36x+ speedup" and the repository owner
recalled ~96x at 1e6 points from an earlier (now-unavailable) benchmark run. Neither
number is what this run measured. The largest speedup **actually measured** (both
libraries run, no extrapolation) is **59.9x at N=20,000**; the largest **extrapolated**
figure (CPU cost extrapolated from its own measured per-point cost, GPU side measured
directly) is **~67x at N=1,000,000**. The panel's `panel-stat` badge text
("36×+ speedup") and the bullet claiming "36×+ speedup" in the GPU IAPWS-95 project
description should be updated to reflect the measured 59.9x / extrapolated ~67x, not
left at 36x or bumped to 96x — neither is supported by this run. See the "Report back"
section below.

## Summary of claims the measurements do not support

1. **"36×+ speedup" (IAPWS-95 GPU project badge and bullet).** Not supported as
   written. Measured: up to 59.9x (actually run, N=20,000); ~67x extrapolated at
   N=1,000,000. The owner's recalled ~96x is also not what this run reproduced. See
   figure 1's caption note above.
2. **"Wrote finite-difference and physics-informed neural network (PINN) solvers for
   transient single-channel analysis"** (SCA suite project bullet). Per
   `docs/DECISIONS.md` ("Scope: transient is elsewhere"), transient SCA lives in a
   separate repository not covered here; this bullet is not supported by anything in
   this repository and should be reworded or removed, per that decision (not a new
   finding of this phase — flagged here again because it is exactly the kind of
   page claim this phase was asked to check for).
3. **"Implemented multiple literature-published correlations per property"** (liquid
   metal project bullet). Per `docs/DECISIONS.md` ("Scope: liquid metals"), this is not
   supported by the repository (one correlation per property) and was already flagged
   for rewording at Phase 7 by that decision.
